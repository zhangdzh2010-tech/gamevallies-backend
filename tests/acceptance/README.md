# 分类作品真实验收

`artifact-seeds.json` 提供每类4个种子请求及人工交互断言。生成完成不等于验收通过：必须打开作品、执行检查、检查控制台错误，再发布自己的合格种子作品。保留失败任务，不得从分母中删除；修复后使用新版本分组，不能混入旧版数据。

游戏保留已有分层玩法/趣味/视觉门槛。工具权重为功能40%、交互25%、易用20%、清晰15%；科学演示为科学正确35%、参数真实性25%、解释25%、清晰15%。后两类总分至少7，关键维度最低分见 `contracts/generation/quality-policy.json`。运行失败或致命内容错误不可由总分抵消。AI内容审核提供证据，不能代替数学数值断言或领域专家验证。

每次真实任务在JSONL记录 `run_id`、`version`（实际部署SHA）、`kind`、`status`（passed/failed/pending）、`attempts`（包含内部修复和重试）、`environment`（production）、`evidence_url`，可附 `checks`、`failure_reason`、`work_id`。若不能确认尝试次数，先补查日志，不得默认首次成功。部署测试、模拟LLM、单元测试不能计入生成成功率。

运行 `python scripts/summarize-generation-acceptance.py <ledger.jsonl>`。同时输出首次通过数、最终通过率、待完成数和单侧95%精确二项下界。总体至少299个具有代表性的独立样本全部成功，才足以使该下界超过99%；若每个类别都声称99%，则每类都需要相应证据。固定少量种子反复生成不代表全体用户请求分布。剩余额度不足时明确未证实目标，不绕过额度或伪造数据。
