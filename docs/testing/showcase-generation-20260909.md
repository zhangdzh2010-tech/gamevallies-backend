## 已实施的本地修复

1. **正常秒级倒计时被误杀。** 旧检查仅观察750ms，合法的每秒更新无法稳定通过。改为100ms分段观察，最长2200ms，发现变化立即结束。仍拒绝仅改变按钮文字但不推进的计时器。以原HEAD重放新增回归用例，确认失败；新实现通过。生产失败计时器未保存候选HTML，因此该局部复现证明检查缺陷，不冒称已逐行检查原始作品。
2. **空代码分区诱导作用域破坏。** 标记归一化会在IIFE前插入空CONFIG/INPUT等分区；旧协议将其宣称为安全补丁锚点。实际失败作品的外部handler引用IIFE内的`inputBound`。现在仅列出非空锚点，拒绝向空脚本分区插入代码；整段替换同样受保护，提示明确保留闭包作用域。该保护不能替代全部JavaScript语义检查。
3. **失败交互作品无法回放。** 最终失败保留候选HTML及交互/分类审核报告，通过现有作者权限控制的任务产物接口保存，不把源码塞入进度消息。
4. **大桌面验收与真实预览尺寸不一致。** 增加1000×460、1000×600检查，保留1366×768、1920×1080。当前自动门槛仍主要检查横向溢出和内容变化，不声称已自动证明首屏构图、科学正确性或全部控件行为。
5. **科学绘图和初始化约束不足。** 生成提示加入尺寸观察、延迟初始化及重绘要求；审核提示加入箭头端点、坐标映射、角弧方向检查。提示加强不能保证模型执行正确，仍需逐作品的数值和视觉验收。
