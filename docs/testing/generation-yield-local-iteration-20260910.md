## 本次改动

工具和科学作品有完整原稿时直接生成精确补丁。所有修改引用同一份原稿，先
验证全部位置，再按原稿偏移一次应用；拒绝重叠、依赖前一补丁结果、累计替换
超过 60%、输出过大、未实际改动及未知操作。最多两个候选请求，补丁格式错误
可以在剩余预算内纠正一次，不会因此重写原稿。修复阶段继续携带原修改要求。
最终仍需桌面沙箱、交互与分类审核。首次新作仍从完整生成开始。

小游戏审核增加结构化 findings：问题、评分维度、唯一的原文引用、理由、
修正建议、所属区域和修改范围。每个问题、否定完整性/玩法/难度的判断，以及
低于 7 的分项评分均需引用。这里的 7 是审核解释要求，不是新的作品通过门槛。
布尔值和评分按真实类型、有限数值与范围解析。无效审核只纠正一次；仍无效或
服务异常则保留原候选与诊断，创建链路不会因审核异常重新生成或自动放行。

在原有静态、合同与运行检查通过之后，有源码引用且明确为 SCRIPT/STYLE
局部缺陷的游戏可以进入两轮局部修复，即使完整性为 false 或总分差距较大。
缺少真实玩法、需要重新设计或需要 BODY 变更仍不走此分支。补丁需重验合同、
运行行为与审核结果；原有分数阈值和修复回退保护不变。引用与局部修正建议
进入作者可读取的失败诊断。移除该路径中与已定位问题无关的泛化美化建议。
