## 事实与原因

### 游戏预检产生整篇重生成成本

`潮汐拾贝` 的三次 `code_generate.full` 日志延迟分别 94.848、83.2、88.0 秒（后两项为界面舍入显示）。最终候选已通过新产物通道保存。原始 SHA256：`058659b3c2d4062f424fa4afb9ef04325e4681c5ddc8667ced21e8122df4911c`。

两个处理函数均出现 `e.touches ? e.touches[0] : e`，随后读取 `point.clientX/clientY`。目前仅绑定 PointerEvent 的路径通常走 `e`，不能把此错误表述为已在真实鼠标点击中崩溃；空触摸列表的兼容分支确有空值风险。预检要求长度保护，模型接收指导后整篇再生成仍保留同样写法。

新增保守的确定性修正：仅识别同一事件对象、同一触摸列表的精确三元式，改成有长度保护的 touches / changedTouches / 原事件回退，不合成坐标，不增加监听器或改作用域。使用现有 Esprima 词法边界排除字符串、注释、正则、模板文本；未知词法结构不修改。若脚本中还有不认识的触摸下标读取则整段不自动修正，避免全局长度检测意外掩盖未修复位置。原候选离线回放从唯一 `unsafe_touch_access` 错误变成预检通过，仅增加 184 字节；这不代表它已通过游戏全链路验收。

### 光学模型自审并不能证明图形正确

模型给《光的折返》9.2 分并声明角弧正确，实际源码将反射弧从 `-π/2-θ` 到 `-π/2` 逆时针绘制，45° 时画 315°、30° 时画 330°。入射箭头也和反射箭头一样朝远离镜面的方向，违背入射含义。没有 504 证据，这不是上游超时导致的失败。

新增 Canvas 运行探针：记录真实 stroke 的弧参数以及 fillText/strokeText 的入射角/反射角标签；仅当标注的小角精确对应实际反向大弧时阻断。完整圆、无光学标签的仪表/装饰、无关角度不纳入；这不是通用科学正确性证明，DOM/SVG 与其他公式仍需独立测试和内容审查。提示同步要求明确检查入射与反射箭头的相反传播方向。

线上 Linux QA 报告称 1000×600 核心控件完整，而独立 macOS Chromium 截图显示控件贴底裁切。字体与运行环境下的布局不等价；不把某一平台的边界通过当跨平台通过。增加 1000×600 根字号 +12.5% 的布局压力检查，为字体度量差异留出余量，不通过缩小文字或隐藏核心操作解决。

### 小游戏修复仍退化成完整脚本

B 的预检错误已消失；一次完整生成耗时 84.238 秒。两轮修复均发生 `search_not_unique:SCRIPT`，旧纠错协议强制返回完整 `replace_section`，且补丁沿用完整生成的输出预算。慢调用证据包含 98.081 / 99.348 / 115.356 秒，输出分别 11592 / 11117 / 14340 tokens。任务事件仅收集慢调用和失败摘要，因此不能当作完整调用账单，也不能从 `httpStatus: null` 推断 504。

修复 `ce10685`：小游戏质量修复及一次格式纠错统一严格 `replace_exact`，最多 12 处，限制累计替换范围，禁止通过大段 search 隐藏整脚本替换；基础预算 4096、截断恢复上限 8192，不改变 Provider 或超时配置。一次纠错仍失败则保留候选和原因，不再因协议错误触发完整重生成。质量阈值与修复后运行验证未放宽。相关回归 192 passed。

### 曲线中心坐标合法不代表线条完整

C 波形经 12 组相位/振幅组合验证：实际 Canvas 逐点满足 y=y1+y2，幅值公式正确；暂停、重置、核心控件和浏览器无异常均通过。但相位 0、A=2 时，293 像素高的画布中，合成曲线中心范围约 0.002～292.998，线宽 3，峰值被裁切。独立证据在 `qa/wave-duet/maximum-amplitude-evidence.json`。不将其坐标正方向向下的约定误报为数学公式错误。

补充门禁考虑变换后的线宽，只对跨越半幅、拥有内部峰谷的连续密集曲线检查贴边裁切；单调坐标轴、多子路径网格、另传 Path2D 的 stroke 不混入。更新生成提示：用最大参数组合计算范围，给线宽留边；多列任务需保留可阅读宽度，编辑和保存提示一致。离线重放波形由漏检变为拒绝；周计划的可读性仍需独立视觉验收，不能声称这个几何探针能识别一切排版缺陷。
