# GameVallies 优化方案与任务清单

日期：2026-09-05。范围：前端、NestJS 业务服务、Python AI 引擎与交付流程。

## 目标与证据边界

最高优先级是用户测试反馈的生成成功率低、作品同质化高。架构调整服务于可玩率、需求满足度、差异化、成本和可维护性。尚未取得生产任务样本、真实模型评测结果及部署网络配置；不能用单元测试通过率替代产品成功率。

保留 Taro/React、NestJS、FastAPI、MySQL、Redis 和现有服务部署。上一轮大文件拆分仍在草稿 PR，后续行为修改采用独立优化分支，便于分开审查和回退。未经上线验收不合并、不部署。

## 整体方案

1. **成功率**：区分请求完成、代码可运行、玩法闭环、需求满足与用户认可。建立固定需求集、失败分层、候选版本与执行耗时记录。先验证核心玩法，再追加表现；修复保留需求与可玩约束，不降低质量门槛冒充成功。
2. **创意与个性化**：在需求解析阶段提出互有区别的玩法候选，按用户明确约束、实现难度和机制差异选择。把核心操作、目标、约束、反馈和独特规则写入结构化设计，后续生成和修复共同使用。第一阶段使用显式需求；行为画像需在有数据和用户可控偏好入口后实施。
3. **可靠执行**：GenerationTask 是任务权威记录，区分会话提交、执行成功和发布。逐步统一队列投递、执行编号、取消、恢复和结果提交。生产模式不静默降级为进程内生成；数据库事务与队列投递最终采用可恢复的 outbox。
4. **额度与订阅**：创建、迭代、解锁归属统一权益模块；原子扣减、任务唯一预占、结算及释放流水。保持当前“额度不足可生成、订阅后解锁”行为，直到该商业规则另行确定。续费延长与升级折算也需要产品规则，不擅自改变已有权益。
5. **隔离**：生成 HTML 使用最小 iframe 权限；QA 浏览器禁止不必要的网络访问。独立游戏来源、容器权限、网络出口和资源限制必须结合实际部署验收。
6. **领域边界**：创作会话、生成协调、权益、AI 流水线、质量检查、产物发布、社区信息流分别拥有写入职责。先在现有服务内建立模块边界，再根据负载决定独立部署。
7. **交付与性能**：修复 CI 脚本失配，执行实际回归；前端从源码构建。热门流从全量排序转为可衡量的候选集/预计算方案，保持分页规则明确。

## 产品评测方法

固定需求覆盖休闲、动作、解谜、策略、教育与明确复刻要求。每个需求多次使用不同种子；新旧版本使用相同模型、配置及预算比较，禁止只挑成功作品。

- 端到端可玩率：可启动且核心操作/目标/终局或持续循环通过的任务数 ÷ 全部任务数。
- 需求满足度与趣味性：单独人工验收，不能从“模型返回成功”推断。
- 差异化：以机制、操作、目标和约束比较；文字指纹只用于筛查，不等于语义新颖度。
- 成本：累计失败、修复、备用请求的花费，再除以通过验收的作品数。
- 时延：分阶段与全流程 p50/p95；缺失记录不补零。

上线门槛以基线对照结果确定。此时不承诺未经测量的成功率提升百分比。

## 发布与回退

提交优化分支及草稿 PR，逐项记录代码、测试和外部依赖。无数据库迁移的改动可按提交回退；后续 schema 变更采用先兼容读写、再迁移、最后清理。真实模型批量评测会产生费用，先提供离线评测与固定样本；使用实际模型时遵守已配置的预算和执行授权。

### 复现命令

```bash
npm ci
npx prisma generate
npm run build --workspace=game-service
npm run build --workspace=@gamevallies/feed-service
npm test --workspace=game-service -- --runInBand test/game.service.spec.ts test/game-locking.spec.ts test/creation-session.service.spec.ts
npm test --workspace=@gamevallies/feed-service -- --runInBand test/trending-production.spec.ts
python scripts/sync-quality-policy.py --check
python scripts/evaluate-generation.py task-results.jsonl --output evaluation.json
```

Python 依赖及测试列表见 `.github/workflows/generation-refactor-tests.yml`。评测输入每行一个任务，`cost` 必须同一币种且包含该任务所有失败与重试花费；字段不完整时工具保留 unknown，不推算成功。
